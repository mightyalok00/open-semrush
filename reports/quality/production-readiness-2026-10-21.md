## Controls and security hardening verified against latest code

### 1. HTML Escaping and UI XSS Defense (`public/app.js`)
- **Backtick Escaping**: `escapeHtml` escapes backticks (`` ` ``) along with `&`, `<`, `>`, `"`, and `'`.
- **Safe DOM Event Binding**: Replaced inline `onclick` string interpolation (`onclick="...${escapeHtml(q)}..."`) in PAA and SERP rows with DOM elements using `.textContent` and `.addEventListener('click', ...)`.
- **AI Action Fix Binding**: Converted inline `onclick` handlers on code fix buttons to HTML5 `data-*` attributes (`data-url`, `data-code`, `data-original`, `data-message`) and attached click listeners via query selectors, eliminating script injection vectors.
- **Unescaped Layout Variables**: Escaped all previously raw fields in AI strategy generation (`targetIntent`, `recommendedWordCount`, `estimatedDifficulty`, and error alerts).

### 2. Persisted-Data Schema Validation (`src/storage.ts`)
- **Strict Schema Enforcement**: `validateDb()` inspects and validates every object in `projects` and `history`.
  - `projects`: requires string `id`, valid `domain`, timestamp string `createdAt`, score bounded `0 <= lastAuditScore <= 100`, and an array containing only strings for `trackedKeywords`.
  - `history`: requires valid `domain`, timestamp string, score bounded `0 <= healthScore <= 100`, and non-negative integers for `errors`, `warnings`, and `notices`.
- **Input Clamping**: `recordAuditInHistory()` clamps health scores to `[0, 100]` and count inputs to non-negative integers before appending.
- **Fail-Closed Durability**: Corrupt or schema-breached files cause explicit errors and preserve raw disk bytes without silent overwriting or data loss.

### 3. Trusted Reverse-Proxy IP Parsing (`scripts/production-controls.mjs`)
- **Canonical IP Sanitization (`cleanIpCandidate`)**: Strips IPv4/IPv6 port numbers (`198.51.100.1:8080`), bracketed IPv6 notation (`[2001:db8::1]:443`), and interface zone indexes (`fe80::1%eth0`). Validates candidates using `node:net`'s `isIP()`.
- **Spoofing & Injection Rejection**: Non-IP candidate strings (e.g. containing HTML tags, SQL fragments, or malformed octets) are rejected; `parseClientIp()` cleanly falls back to `socket.remoteAddress`.
- **Configurable Proxy Depth**: `TRUST_PROXY_HOPS` safely extracts the authentic client IP behind Cloudflare, AWS ALB, Nginx, or Caddy.

### 4. Scalable Architecture for Larger Deployments
- **Storage Adapter Abstraction (`StorageAdapter`)**:
  - `src/storage.ts` exports the `StorageAdapter` interface and `JsonFileStorageAdapter`.
  - Applications can swap in a distributed store (e.g., PostgreSQL, Redis, DynamoDB, MongoDB) by implementing `StorageAdapter` without changing any route handling or controller logic.
- **Pluggable Rate Limiter (`RateLimiterStore`)**:
  - `scripts/production-controls.mjs` exports `MemoryRateLimiterStore` and accepts an optional `store` in `checkProductionControls()`.
  - Multi-replica cluster deployments can plug in a shared Redis-backed rate limiter store for unified quota enforcement across multiple container instances.
